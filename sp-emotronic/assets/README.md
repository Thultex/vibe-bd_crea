# Assets Emotronic

Dieser Ordner ist für spätere allgemeine Emotronic-Medien vorgesehen.

Die unmittelbar für die installierbare PWA benötigten Icons bleiben gemäß Repository-Regeln gemeinsam mit dem Tool unter `../tools/emotronic-pwa/`.

Die repositoryweit auslieferbaren Audiodateien liegen gemäß Sound-Workflow unter `../../assets/audio/emotronic/`. Dort befinden sich die Sets `8-bit` und `8-bit_soft` samt Manifest; erzeugt werden sie durch `../tools/emotronic-pwa/generate_audio_assets.py`.
