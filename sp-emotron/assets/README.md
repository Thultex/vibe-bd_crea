# Assets Emotronic

Dieser Ordner ist ausschließlich für spätere allgemeine Spielmedien vorgesehen, die nicht zur installierbaren App gehören.

Sämtliche PWA-Laufzeitdateien einschließlich Icons und optionalem Audio liegen in der maßgeblichen Quelle `../tools/emotronic-pwa/` und vollständig gespiegelt unter `../../share/apps/emotronic/`. Das Set `8-bit_soft` samt Manifest wird durch `../tools/emotronic-pwa/generate_audio_assets.py` in beiden Bäumen synchronisiert. Die klassische Standardvariante wird direkt per Web Audio synthetisiert.
