Emotronic als App installieren

Voraussetzung
Die Dateien müssen über HTTPS oder lokal über localhost bereitgestellt werden. Direktes Öffnen der index.html per file:// reicht für eine installierbare Web-App nicht aus, weil Service Worker dort gesperrt sind.

Android / Chrome
1. Die bereitgestellte HTTPS-Adresse öffnen.
2. Browsermenü öffnen.
3. „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.

iPhone / Safari
1. Die bereitgestellte HTTPS-Adresse in Safari öffnen.
2. Teilen-Schaltfläche öffnen.
3. „Zum Home-Bildschirm“ wählen.

PC / Chrome oder Edge
1. Die HTTPS-Adresse öffnen.
2. Das Installationssymbol in der Adressleiste wählen.

Enthalten
- manifest.webmanifest
- Service Worker sw.js
- Icons für Android, iPhone und Maskable Icons
- Offline-App-Shell
- Zwischenspeicherung verwendeter OpenMoji-Grafiken
