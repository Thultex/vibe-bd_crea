# Ruckpacken – Spielanleitung v1.00

## Spielidee

Spielende legen Karten überlappend aus. Jede Karte zeigt neun Gegenstände. Beim Legen werden mindestens drei und höchstens sechs Symbole verdeckt. Nur sichtbare Symbole zählen für geheime Aufgaben. Aus den sichtbar gehaltenen oder verdeckten Gegenständen können die Mitspielenden auf fremde Aufgaben schließen.

## Aufgaben

- **A – Kombo:** Eine semantische Kategorie bringt Punkte, etwa alle weichen Gegenstände oder alle Gegenstände für den Wald. Das erste passende Symbol zählt `+1`, jedes weitere verdoppelt den Wert.
- **B – Anti:** Jedes passende sichtbare Symbol zieht einen Punkt ab, etwa jeder laute Gegenstand.
- **C – Bonus:** Vorgegebene Mengen oder Nachbarschaften bringen einen festen Bonus, etwa dreimal „Essen“ direkt an „Kochen“.

Kinder erhalten eine Aufgabenkarte. Erwachsene erhalten zwei: Aufgabe A muss von einer Symbolkarte erfüllt werden und B von der anderen; C darf frei wechseln.

## Zug

Eine neue Karte darf gedreht und auf bereits liegende Karten gelegt werden. Nach dem Legen müssen drei bis sechs ihrer Symbole verdeckt sein. Danach werden ausschließlich die sichtbaren Symbole gewertet.

## Spielende

Rundenzahl und Zielpunktzahl werden im Prototypentest kalibriert. Bis dahin endet eine Partie nach einer vorher vereinbarten Zahl gelegter Karten; die höchste Punktzahl gewinnt.
